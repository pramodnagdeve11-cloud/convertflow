# DocuFlow Studio
### Universal All-in-One PDF, Image & Office Suite (100% Client-Side)

DocuFlow Studio is a universal document, image, and media processing suite built to run **100% in your browser** without any server costs or external file uploads.

---

## 🌟 Complete Tool Suite (सभी 19 टूल्स)

### 1. Convert from PDF (PDF से बदलना)
- **PDF → Word (.docx)**: Editable Microsoft Word document with layout preservation and OCR.
- **PDF → Excel (.xlsx / .csv)**: Extracts data tables directly into genuine Excel spreadsheets using SheetJS.
- **PDF → PowerPoint (.pptx)**: Renders PDF pages as Microsoft PowerPoint presentation slides using PptxGenJS.
- **PDF → JPG / PNG**: High-resolution image extraction (72 to 300 DPI) and ZIP archive download.
- **PDF → Text (.txt) & HTML**: Clean plain text extraction and styled HTML code generation.

### 2. Convert to PDF (PDF में बदलना)
- **JPG / PNG / WebP → PDF**: Merge photos into PDF with margins, orientation, and custom KB/MB target limit.
- **Word (.docx) → PDF**: Convert Word documents into standard A4 PDF files.
- **Excel (.xlsx / .csv) → PDF**: Convert tabular spreadsheets into formatted PDF documents.
- **Text (.txt) & HTML → PDF**: Direct conversion into clean PDF files.

### 3. PDF Utilities (PDF टूल्स)
- **Merge PDF**: Combine multiple PDF files into one with reordering.
- **Split PDF**: Separate specific pages or custom page ranges (e.g. `1-3, 5`).
- **Compress PDF**: Shrink file size up to 80% with Extreme, Recommended, or Low compression.
- **Organize & Delete Pages**: Visually delete unwanted pages and re-arrange page order.
- **Rotate PDF**: Rotate individual pages or all pages 90°, 180°, or 270°.
- **Watermark & Page Numbers**: Add custom diagonal text stamps (`CONFIDENTIAL`, `DRAFT`) and bottom page numbering.
- **Password Protect PDF**: Secure documents with custom encryption and password locking.

### 4. Photo & Image Tools (फ़ोटो कन्वर्ज़न)
- **Image Format Converter**: Convert seamlessly between JPG, PNG, WebP, GIF, and BMP.
- **Image Size Adjuster (KB / MB)**: Tune exact file sizes for UPSC, SSC, and portal forms (20KB, 50KB, 100KB) with Before/After live comparison.
- **Resize & Crop Image**: Custom width, height in pixels, aspect ratio lock, and cropping.
- **Remove Background**: Automatically turn solid or white backgrounds into transparent PNGs (perfect for signatures and logos).

### 5. Media & Audio Tools (मीडिया कन्वर्ज़न)
- **Video to Audio (MP4 → WAV/Audio)**: Extract audio tracks directly from MP4 and WebM videos using browser Web Audio API.
